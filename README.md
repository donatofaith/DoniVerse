# DoniVerse

**Your whole campus world, in one place.**

DoniVerse is a student-focused campus companion for navigation, student journey tracking, campus events, communities, help resources, and day-to-day campus discovery.

## Core experience

- Explore campus places and get walking directions
- Track student registration/journey steps
- Discover approved campus events and communities
- Access trusted campus help contacts
- Student accounts, onboarding and guest mode
- Admin moderation for events and platform content

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Supabase
- Leaflet / OpenStreetMap
- Vercel

## Development

```bash
npm install
npm run dev
```

For production-style local testing:

```bash
npm run build
npm start -- --hostname 0.0.0.0
```
